# NutriAI — Intelligent Nutrition & Meal Planning Platform

Platformă web modernă de nutriție asistată de AI pentru generare de planuri alimentare personalizate, calcul automat de macronutrienți și asistent conversațional de nutriție.

## 📌 Tehnologii propuse
- **Frontend:** Next.js / Vite + React / Modern Vanilla CSS (Design modern, curat, responsive)
- **Backend / AI Integration:** Python (FastAPI) sau Node.js / Serverless API routes conectate la LLM (Gemini / OpenAI API)
- **Database & Auth:** Supabase / PostgreSQL
